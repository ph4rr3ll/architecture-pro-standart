### **2. Список крупных задач для каждой системы**

**1. Сервис НСИ:**
- T1: Разработка REST API эндпоинта для получения списка актуальных ставок (для кол-центра)
- T2: Реализация scheduled task (компонента выгрузки) для генерации CSV-файла со ставками
- T3: Интеграция компонента выгрузки с внутренним SFTP-сервером банка
- T4: Разработка административного интерфейса для настройки параметров выгрузки (расписание, формат)
- T5: Добавление механизма кэширования часто запрашиваемых ставок в Redis (опционально, для производительности)

**2. Система кол-центра:**
- T6: Разработка нового UI-раздела "Депозитные ставки" в интерфейсе оператора
- T7: Интеграция с API НСИ для получения актуальных ставок
- T8: Реализация кэширования ставок на стороне кол-центра (TTL = 1 час)
- T9: Добавление индикатора актуальности данных (дата/время последнего обновления)

**3. Инфраструктура банка:**
- T10: Настройка и развертывание SFTP-сервера (или выделение ресурсов на существующем)
- T11: Настройка VPN-доступа или правил фаервола для партнёрского кол-центра
- T12: Создание учётных записей и SSH-ключей для партнёра
- T13: Настройка мониторинга доступности SFTP-сервера и процесса выгрузки

**4. Партнёрский кол-центр (внешняя система):**
- T14: Разработка скрипта/процедуры автоматического скачивания файла с SFTP
- T15: Реализация парсера CSV-файла и загрузки данных во внутреннюю систему
- T16: Настройка расписания автоматической загрузки (ежедневно после 9:30)
- T17: Адаптация интерфейса оператора для отображения новых данных о ставках

**5. Депозитный конвейер:**
- T18: Модификация процесса обработки заявки для вызова API НСИ при расчете ставки
